Step 6 · Ship · GitHub + Vercel

Deploying for free

  1. One prompt deploys it and adds the PR check.
  2. Connect the repo in Vercel once: every PR gets a preview link.
  3. Merge only when the check is green.
  4. Merge to main and it’s live.

# with the Vercel MCP connected:

Deploy this app to Vercel and give

me the live URL.

Then add a GitHub Action that runs

npm run check on every pull request.

RUN: on the PR from step 5, point at the green check and the Vercel preview comment, open the preview on your phone, then click Merge. Vercel deploys main to production in about a minute. FALLBACK: merge the rehearsal PR instead. —— Nobody needs to write the CI file by hand: this one prompt deploys the app through the Vercel MCP and has the agent write the GitHub Action. Connecting the repo in the Vercel dashboard (Add New → Project → import from GitHub) is the one manual step, and it’s what puts a preview link on every PR. GitHub Actions is free on public repos. Vercel Hobby is for non-commercial use, which fits a hackathon. Never put model API keys in NEXT_PUBLIC_ variables.
