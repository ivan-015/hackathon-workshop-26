Paso 6 · Publicar · GitHub + Vercel

Publica gratis

  1. Un prompt la despliega y agrega el check de PR.
  2. Conecta el repo en Vercel una vez: cada PR tiene un link de preview.
  3. Haz merge solo cuando el check esté en verde.
  4. Merge a main y ya está en vivo.

# con el MCP de Vercel conectado:

Despliega esta app en Vercel y

dame el link en vivo.

Luego agrega una GitHub Action que

corra npm run check en cada PR.

CORRER: en el PR del paso 5, señala el check en verde y el comentario con el preview de Vercel, abre el preview en tu teléfono y luego haz clic en Merge. Vercel despliega main a producción en más o menos un minuto. PLAN B: haz merge del PR del ensayo. —— Nadie tiene que escribir el archivo de CI a mano: este prompt despliega la app con el MCP de Vercel y hace que el agente escriba la GitHub Action. Conectar el repo en el panel de Vercel (Add New → Project → importar desde GitHub) es el único paso manual, y es lo que pone un link de preview en cada PR. GitHub Actions es gratis en repos públicos. El plan Hobby de Vercel es para uso no comercial, lo cual encaja con un hackathon. Nunca pongas API keys del modelo en variables NEXT_PUBLIC_.
