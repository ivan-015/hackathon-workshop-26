Paso 4 · Construir una tarea · MCP de Supabase

Crea la base de datos

# conecta el MCP de Supabase a un proyecto de prueba:

Crea una tabla jobs (photo_url, part, manual_page, note,

user_id). Activa RLS para que cada usuario vea solo sus

filas. Agrega un bucket para fotos.

Por qué importa RLS: Moltbook filtró cerca de 1.5 millones de API keys porque su llave pública de Supabase salió con RLS apagado. Las herramientas de IA suelen omitirlo si no se lo pides.

Conecta solo los MCP que necesitas. Cada uno consume contexto del agente y puede traer riesgo de prompt injection.

CORRER (ventana 1): pega el prompt de la diapositiva: Crea una tabla jobs (photo_url, part, manual_page, note, user_id). Activa RLS para que cada usuario vea solo sus filas. Agrega un bucket para fotos. Genera los tipos de TypeScript. Cuando termine, escribe: muéstrame la política de RLS que creaste. Esta es la mitad de base de datos de la tarea “Guardar una nota de trabajo”. PLAN B: abre el panel de Supabase y muestra la tabla jobs y su política del ensayo. —— El agente crea la tabla, la política, el bucket y los tipos a través del MCP, sin hacer clic en el panel. Apúntalo a un proyecto de prueba, nunca a producción. Luego pídele que muestre la política de RLS para que el público vea que existe. Neon es una buena alternativa si solo necesitas Postgres; Supabase también incluye almacenamiento y login.
